# Games

Open any of these files in a web browser to play. No install needed.

## Rail Rush (`index.html`)
A 3D endless runner. Dodge trains and barriers across three tracks, grab coins, and see how far you get.

- **Move:** ← → (or A / D), or swipe left/right
- **Jump:** ↑ (or W / Space), or swipe up. Jump over red-and-white barriers.
- **Roll:** ↓ (or S), or swipe down. Roll under yellow-and-black barriers.
- **Pause:** P or Esc

**Customize avatar** lets you change skin, hair, clothes, hats and extras. Coins you collect are saved and can unlock the Crown (150) and the Cape (100).

## Star Catcher (`star-catcher.html`)
Catch falling stars, dodge rocks, and grab hearts for extra lives.
